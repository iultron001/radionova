What is RadiNova AI doing?

A plain-English breakdown of the clinical vision, how medical computer vision works, and how models are trained from scratch.

You upload a medical scan (like a Chest X-ray or Limb X-ray). The system immediately:

🧠 Section 01 · Fundamentals

What is a Model & How Does It Learn?

Understanding weights, loss, backpropagation, and epochs without needing a math degree.

An AI "model" is fundamentally a mathematical network with over 7 million knobs (called weights). At the start, these knobs are set to random values. "Training" is the process of gradually fine-tuning every single knob until the model reliably produces correct diagnostic answers.

1
Forward Pass — Making a Prediction
An X-ray image (224×224 pixels) passes forward through the network layers. The model outputs diagnostic probabilities — for example, "72% Pneumonia, 28% Normal". Initially, this is pure guesswork.
2
Loss Calculation — Measuring the Mistake
We compare the model's guess to the true doctor label using Cross-Entropy Loss. If the patient is actually Normal, the loss is high. If the model was confident and correct, the loss is near zero.
3
Backpropagation — Tracing the Responsibility
PyTorch calculates mathematical derivatives (gradients) working backwards from the loss through all 7 million weights, determining which specific knobs contributed to the error.
4
Optimizer (AdamW) — Nudging the Knobs
The AdamW Optimizer nudges every weight in the direction that lowers the loss. The size of this step is controlled by the Learning Rate (e.g. 0.0001).
5
Epoch Iteration — Cumulative Mastery
Processing all 11,000+ training images once is called 1 Epoch. In this project, training runs for 10 epochs until diagnostic sensitivity reaches its peak.
🍳 Culinary Analogy
Imagine a chef perfecting a secret soup recipe. They taste it (forward pass), note it's too salty (loss), trace it to adding 3 spoons of salt (backprop), and use only 1 spoon next time (optimizer update). Repeat 100 times until the soup is perfect.
📐 Section 02 · Deep Learning Architecture

The DenseNet-121 Neural Network

Why DenseNet-121 is the gold standard for clinical radiological computer vision.

Unlike standard networks where signals pass only from one layer to the next, in a Densely Connected Convolutional Network (DenseNet), every layer receives inputs from all preceding layers. This ensures fine textures (like subtle lung opacities) are never washed out.

# How an X-Ray flows through RadiNova's DenseNet-121 Input Scan (224×224 px, RGB Normalized) │ ▼ DenseBlock 1 (6 layers) → Low-level edges, rib outlines & sharp contours │ ▼ DenseBlock 2 (12 layers) → Geometric textures & soft tissue density transitions │ ▼ DenseBlock 3 (24 layers) → Anatomical organ boundaries (cardiac silhouette, diaphragm) │ ▼ DenseBlock 4 (16 layers) → Clinical consolidation & focal infiltrates ★ Grad-CAM Target Layer │ ▼ Classifier Head → Dropout(p=0.3) + Linear(1024 → 2 classes) │ ▼ Diagnostic Output → [P(NORMAL), P(PNEUMONIA)]
🔍 Architectural Highlights in Code
Located in model/base_classifier.py:
  • Backbone: Pre-trained PyTorch torchvision.models.densenet121
  • Feature Hook: model.features.denseblock4 is intercepted for Grad-CAM gradient mapping.
  • Custom Head: 1024-dimensional feature vector mapped through 30% dropout to prevent overfitting.
⚡ Section 03 · Strategy

Transfer Learning — The Smart Shortcut

Why training from scratch is wasteful, and how a two-stage fine-tuning strategy yields 94.8% recall.

Training 7 million weights from random noise requires millions of images and weeks of cluster compute. Instead, we take a model pre-trained on ImageNet (1.2 million images) that already knows how to see edges, curves, and textures, and transfer that vision to X-rays.

🔒 Stage 1: Classifier Head Warmup (Epochs 1–2)
The entire DenseNet backbone is frozen (its weights cannot change). Only the final classifier linear layer is updated at a higher learning rate (lr=1e-3).
Python · train_chest.py 
# Stage 1: Freeze all feature extractor layers
for param in model.features.parameters():
    param.requires_grad = False

optimizer = torch.optim.AdamW(model.classifier.parameters(), lr=1e-3, weight_decay=1e-2)
🔓 Stage 2: Deep Fine-Tuning (Epochs 3–12)
We unfreeze denseblock4 + norm5 + classifier, training them with a gentle learning rate (lr=1e-4) and cosine annealing. This specializes the deepest diagnostic feature detectors without corrupting early edge filters.
Python · train_chest.py 
# Stage 2: Unfreeze denseblock4 & final normalization
for name, param in model.features.named_parameters():
    if "denseblock4" in name or "norm5" in name:
        param.requires_grad = True

trainable_params = [p for p in model.parameters() if p.requires_grad]
optimizer = torch.optim.AdamW(trainable_params, lr=1e-4, weight_decay=1e-2)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=10)
💡 Why This Two-Stage Flow Wins
If you train an unfrozen model immediately with a randomized head, large initial gradients destroy the pre-trained ImageNet filters. Freezing first preserves visual acuity.
🔄 Section 04 · Pipeline Lifecycle

The 5-Phase End-to-End Flow

From downloading from Kaggle to stratified splitting, data augmentation, and final weight checkpoints.

P0
Phase 0: Dataset Acquisition (Kaggle)
Downloaded from paultimothymooney/chest-xray-pneumonia. Contains 14,054 JPEG images categorized into NORMAL and PNEUMONIA folders.
P1
Phase 1: Deterministic 80/10/10 Stratified Re-Split
The original Kaggle validation set had only 16 images (statistically flawed). Script prep_chest_xray.py merges all images and performs an 80% Train / 10% Validation / 10% Test stratified split using seed 42, written to chest_xray_manifest.csv.
P2
Phase 2: Medical Data Augmentation
During training, images are resized to 224×224 and augmented with random horizontal flips (p=0.5), subtle rotations (±10°), and brightness/contrast jitter to prevent over-memorization.
P3
Phase 3: Class Imbalance Correction
Pneumonia cases outnumber Normal cases (~8.2k vs ~5.8k). We calculate inverse class weights: w_norm = total / (2 × n_norm) and supply them to nn.CrossEntropyLoss(weight=class_weights) so Normal cases are penalized proportionately.
P4
Phase 4 & 5: Checkpointing & Test Evaluation
Every epoch's validation F1 score is tracked. When a new high score is reached, the model weights are checkpointed to model/weights/chest_densenet121.pth. Finally, the best checkpoint is evaluated on the untouched test split.

⭐ Why Recall / Sensitivity is #1 in Healthcare
In medical triage, a False Negative (telling a sick pneumonia patient they are healthy) can be fatal. A False Positive (flagging a healthy patient for review) simply prompts a doctor's secondary check.

Sensitivity = TP / (TP + FN) → 94.8% means out of 1,000 pneumonia patients, our model catches 948 immediately.

🔥 Section 07 · Explainable AI

Grad-CAM Visual Heatmaps

Peering inside the black box — how gradients are converted into localized diagnostic heatmaps.

Doctors cannot trust a simple probability number without clinical rationale. Grad-CAM (Gradient-weighted Class Activation Mapping) traces the final classification score back to feature maps in denseblock4 to reveal what parts of the lung informed the diagnosis.

1
Gradient Extraction
Compute the gradient of the winning class score with respect to each of the feature maps in denseblock4.
2
Global Average Pooling of Gradients
Average the gradients across spatial dimensions to yield an importance weight α for each feature channel.
3
Weighted Linear Combination + ReLU
Multiply feature maps by their weights and pass through ReLU to retain only features that positively contributed to the diagnosis.
4
Jet/Turbo Color Overlay
The 2D activation map is resized back to 224×224 and blended with the original grayscale radiograph. Red regions mark parenchymal lung consolidation.
💡 Doctor Analogy
Grad-CAM is the digital equivalent of a radiologist circling a cloudy lung zone with a red highlighter pen and explaining: "This specific consolidation pattern is why this patient has pneumonia."
